# Commercial Licensing

The AI GM bot's source code is licensed under the **GNU Affero General Public License v3.0 (AGPL-3.0-or-later)** — see [LICENSE](LICENSE). For the overwhelming majority of users, that's free, and asks nothing of you beyond what's already true of any self-hosted table: run it, modify it, share your changes if you distribute your modified version or run it as a service.

**You do not need anything on this page if you're:**
- A GM self-hosting the bot for your own table (even with private modifications you never distribute)
- A hobbyist forking it, improving it, and sharing those improvements back under AGPL
- A community running an open-source fork, as long as the fork stays AGPL and its source stays available to the people using it

## When you'd want a commercial license instead

AGPL's Section 13 requires that if you run a *modified* version of this bot as a network-accessible service for others, you make the Corresponding Source of your modified version available to those users. That's the right default for keeping this ecosystem open — but it's a real obstacle for a specific kind of use case: **embedding this bot into a closed-source commercial product**, where you don't want your own product's source exposed as a condition of using ours. For example:

- A VTT hosting provider wanting to bundle a managed/white-labeled version of this bot into their paid hosting product, without open-sourcing their hosting platform.
- A streaming/content platform wanting to embed the bot as a feature of a larger closed-source application.
- Any company wanting to redistribute or resell a modified version of this bot as part of a commercial offering, without AGPL's network-source-disclosure obligation attaching to their own codebase.

A commercial license grants exactly that: the right to use, modify, and redistribute this software as part of a closed-source commercial product, without the AGPL's copyleft/source-disclosure terms applying to your product. It does not change anything about the Game Content licensing (proprietary setting material stays proprietary either way — see [LICENSE](LICENSE)'s Game Content section, and contact us separately if a commercial deal needs to cover that too).

## How this works

This is a standard **dual-licensing** model — the same approach used by MongoDB, GitLab, MySQL, and many other open-core projects: one license for the community (AGPL, free), a separate commercial license for businesses that need different terms. Both licenses cover the same code; which one applies to you is a choice based on how you intend to use it.
