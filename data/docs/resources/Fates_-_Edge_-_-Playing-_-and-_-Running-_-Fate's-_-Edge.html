Fate's Edge — Web Client Guide

v3.0 Real-Time Collaboration Offline-First Author: Nicholas A. Gasper

This guide walks you through using the Fate's Edge Web Client — a browser-based companion that brings your tabletop campaign to life with real-time sync, shared timers, dice rolling, character management, and GM tools. Whether you're a first-time player or a seasoned GM, you'll find everything you need to run a smooth, immersive game.

1. Introduction

The Fate's Edge Web Client is a real-time, offline-first application that lets you run your entire campaign from a single browser window. It's designed to work alongside the Essential Guide and Game Master Screen, providing digital tools that enhance your tabletop experience without getting in the way of the story.

Key features:
  • Live Sync: Every change — character edits, timer ticks, dice rolls — is shared instantly with all connected players.
  • Presence: See who's online, who's editing what, and when someone last acted.
  • Offline Support: Changes are queued when you're disconnected and replayed automatically when you reconnect.
  • Conflict Resolution: Smart merging of simultaneous edits, with a friendly UI to resolve conflicts when they happen.
  • All Core Modules: Characters, Timers, Dice, Wiki, Encounter Builder, Faction Tracker, Bestiary, Patrons, and more.

This guide assumes you have a basic understanding of the Fate's Edge rules — if you're new, start with the Essential Guide.

2. Quick Start

Getting started with the client is easy. Follow these steps to create or join a campaign.

1. Open the client in your browser (you'll be directed to the login page).
2. Create a campaign by entering a unique campaign code and a password (or join an existing one with the code your GM gives you).
3. Set your name and role (GM or Player). This determines what you can see and edit.
4. Create or import your character using the built-in character sheet editor.
5. Start playing! The GM will frame the scene, and you can roll dice, track timers, and update your sheet in real time.

🔐 Security note: The campaign code and password are your only gatekeeping. Share them securely with your group.

4. Core Gameplay with the Client

The client mirrors the core resolution loop from the rulebook, adding digital efficiency.

4.1 Rolling Dice

To roll, simply type /roll 5d10 in chat, or use the dice panel to select Attribute + Skill. The roll will:

  • Count successes (6+), criticals (10s), and Story Beats (1s).
  • Display the result with a breakdown of dice.
  • Broadcast the result to all connected clients.
  • Automatically add Story Beats to the GM's pool.
💡 GM Tip: You can spend Story Beats directly from the GM dashboard to introduce complications — the client will show a log of SB spent.

4.2 Character Sheets

The character sheet is fully editable and syncs live. Players can update Attributes, Skills, Talents, Fatigue, Harm, Boons, and Obligation. When multiple people edit the same sheet, the client resolves conflicts intelligently (see Advanced Features).

Use the Assets & Followers section to manage your off-screen resources, and the Bonds & Complications tab to track relationships.

4.3 Timers

Timers are the GM's primary tool for tension. In the client, you can:

  • Create a timer with a name and segment count (4, 6, 8, or 10).
  • Click +1 to tick it forward; all players see the updated value.
  • Set timers to auto‑tick on Story Beats or roll outcomes (optional).
  • Use the timer as a progress tracker for complex challenges.

Timers are visible to everyone — this transparency drives urgency and shared decision-making.

4.4 Chat & Communication

The chat panel serves as your table talk. It shows:

  • Player messages (with names and timestamps).
  • Dice roll results (with success counts and SB generation).
  • System messages (e.g., "GM spent 2 SB — Guard Patrol arrives").
  • Connection events (player joined/left).

You can also use the chat to declare actions and discuss plans.

4.5 Assets & Followers

The client includes dedicated panels for managing Assets and Followers. Each entry can be linked to a character, and their status (Maintained, Neglected, Compromised) is visible to the GM.

When you activate an Asset by spending a Boon, the client will log it and apply the narrative effect (e.g., "Safehouse — hidden exit revealed").

5. Advanced Features

5.1 Real-Time Synchronization

The client uses WebSockets to keep every connected instance in perfect sync. When you edit a character, tick a timer, or roll dice, the operation is sent to the server, which broadcasts it to all other clients in the same campaign.

  • Incremental updates: Only changes (not full state) are transmitted, making sync fast.
  • Version vectors: Each client tracks which operations they've seen, ensuring no duplicate application.
  • Operation log: The server stores a history of all changes, allowing new clients to catch up.

5.2 Offline Support

If you lose your internet connection, the client continues to work locally:

  • All your actions (rolls, edits, timer ticks) are stored in a local offline queue.
  • When you reconnect, the queue is replayed in order, and your changes are merged with any remote changes.
  • You'll see a status indicator showing whether you're online or offline.
⚠️ Note: Offline changes are applied optimistically — they appear in your local UI immediately. If a conflict arises on reconnection, you'll be prompted to resolve it.

5.3 Conflict Resolution

When two users edit the same field simultaneously, the client detects the conflict and presents a resolution dialog.

  • Field-level merge: If you edit different fields (e.g., one edits Body, another edits Wits), both changes are merged automatically.
  • Same-field conflict: You'll see both versions side by side and can choose "Keep Yours", "Use Remote", or "Merge" (if the client supports merging logic).
  • Dependency errors: If you edit a character that was deleted by another user, the client will warn you.

5.4 Presence & Cursor Awareness

The client shows a list of connected users, their roles, and their last activity. In character sheets and wiki entries, you may see cursors or highlights indicating where others are typing.

This feature makes remote collaboration feel more natural and reduces accidental overwrites.

6. GM Tools

The client provides a suite of tools to help GMs prepare and run sessions efficiently.

6.1 Faction Tracker

You can import or create factions with the following fields:

  • Name, Standing (e.g., -3 to +3), Agenda, Agenda Timer (segments/current).
  • Key NPCs, Resources, Hooks, Color, Icon.
  • Relationships (allies/enemies).

The faction list is synced to all players, but only the GM can edit them. Use the Agenda Timer to track faction progress between sessions.

6.2 Patron Library

The client includes a searchable library of Patrons from the rulebooks. Each entry contains:

  • Lore, domain focus, Rites, Cantors & Cults, Witchcraft, Corruption tables.
  • Thiasos and Codex options for Runekeepers.
  • Patron's Gift and sample adventures.

GMs can assign Patrons to player characters directly from the interface.

6.3 Bestiary

The Bestiary is a catalog of monsters and NPCs, with entries that include:

  • Name, type, summary, locations, lore, connections.
  • Stats (Body, Wits, Spirit, Presence) and special abilities.
  • Harm, Armor, and other combat-relevant data.

GMs can quickly drag creatures into the VTT or use them in encounter building.

6.4 Adventure Management

Adventures are structured as JSON objects with acts, scenes, timers, NPCs, locations, factions, and encounter details. The client imports these and presents them in a clear, act‑by‑act outline.

  • Track which scenes are completed.
  • View all timers for the adventure in one place.
  • Access NPC and location references on the fly.

6.5 Encounter Builder

Use the encounter builder to:

  • Select adversaries from the Bestiary.
  • Set Position, DV, and timer connections.
  • Define outcome branches (Clean, Partial, Miss).
  • Launch the encounter, which will create a shared scene and set up timers automatically.
⚡ GM Power Tip: Use the Deck of Consequences module (if enabled) to generate unexpected twists — the client can draw cards and suggest complications based on suit/rank.

7. Example Session

Let's walk through a short session using the client, from setup to resolution.

Setting Up

  • GM: Creates campaign "Tower of the Sun" and invites 3 players.
  • Players: Join with the code, create their characters (or import from previous sessions).
  • GM: Imports an adventure module (or builds one) and sets up initial timers: Ritual Completion [6], Guard Patrol [4].

Scene 1 — The Approach

  • GM: Describes the tower; asks "What do you do?"
  • Player (Scout): Declares "I sneak ahead to scout the entrance."
  • Player rolls via dice panel: Wits + Stealth = 5d10. Result: 3 successes (Clean), no SB.
  • The roll result appears in chat; GM narrates "You spot the guards — two at the door."
  • GM: Advances the Guard Patrol timer +1 (they're on alert).

Scene 2 — Confrontation

  • Fighter: "I charge the guards!"
  • Fighter rolls Body + Melee, gets 2 successes (Partial) and rolls a 1 (SB).
  • Result: Fighter hits but is grazed; Player gains 1 Boon; GM gains 1 SB.
  • GM: Spends 1 SB: "One guard blows a horn — reinforcements will arrive in 2 rounds." (Tick Reinforcements [4] +1).
  • All players see the timer update in real time.

Scene 3 — The Ritual

  • Mage: Attempts to disrupt the ritual with a [DISPEL] spell.
  • Rolls Spirit + Arcana, gets a Miss (0 successes) and two 1s.
  • Player gains 2 Boons; GM gains 2 SB.
  • GM: Spends 2 SB to trigger a backlash: "The spell recoils, and the ritual accelerates." (Tick Ritual Completion +2).
  • Now the timer is at 5 of 6 — tension is high.

Resolution

  • Players pool their Boons to re-roll key failures.
  • They succeed in stopping the ritual with a Clean Success, but the GM uses the remaining SB to add a complication: "The tower begins to collapse — escape skill challenge!"
  • All timers and rolls are logged; the client keeps a record of the session.

This flow shows how the client enhances the core loop without changing the rules — it just makes everything faster and more visible.

8. Tips & Best Practices

✅ DO
  • Use the chat for all in-game declarations — it creates a log.
  • Name timers descriptively (“Ritual Completion” not “Timer 3”).
  • Spend Story Beats visibly — narrate the complication in chat.
  • Encourage players to update their sheets immediately after marking Fatigue/Harm.
  • Use the offline queue awareness — if you see the offline indicator, save your work locally.
❌ DON'T
  • Rely on the client for everything — keep physical dice for backup if connection is spotty.
  • Ignore conflict resolution dialogs — merging properly saves future headaches.
  • Hoard Story Beats — spend them to keep tension high.
  • Overcomplicate timers — 3 active timers per scene is plenty.
  • Edit the same character simultaneously without discussing — the client handles it, but it's still confusing.

For GMs

  • Prep content in advance: Import factions, patrons, and bestiary entries before session.
  • Use the adventure module: It structures your session and provides built-in timers and encounters.
  • Enable presence indicators: They help you know who's paying attention.
  • Set up a test campaign: Familiarise yourself with the conflict resolution UI before your first real session.

For Players

  • Keep your sheet up-to-date: The GM will refer to it for position and effect.
  • Use the dice roller: It automatically tracks successes and SB — less math, more fun.
  • Chat responsibly: Keep OOC chatter in a separate channel if the table wants it.
  • Embrace Boons: Spend them early and often; they're your dramatic fuel.

9. FAQ

Q: What browsers are supported?

Chrome, Firefox, Edge, and Safari (latest two versions).

Q: Can I use the client offline?

Yes, the client works offline and syncs changes when reconnected. However, you won't see other players' updates until you're online.

Q: How do I resolve a conflict?

When a conflict occurs, a modal appears showing both versions. Choose which version to keep, or merge fields if possible. The client will apply your choice and broadcast it.

Q: Can I import my existing characters from other tools?

Currently, you can import JSON‑formatted character data. We plan to add support for common formats (e.g., D&D Beyond) in future updates.

Q: Is there voice/video built in?

Not at launch, but you can use external tools (Discord, Zoom) alongside the client.

Q: How secure is my campaign data?

All connections are encrypted (WSS), and campaign access is protected by a password. The server stores state only for active campaigns; old campaigns are purged after 30 days.

Q: Where can I report bugs or suggest features?

Use the feedback link in the client's settings panel, or contact the author via the website.
